Entry for the [Snooze Button Roast](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) bounty on [make.fun](https://make.fun).

`main.ts` writes one roast line to `/output/entry.txt`: a single line roasting an alarm clock that rings at 6 AM on a Saturday, deterministically (two runs produce byte-identical output).

Run it with Node 22:

```sh
node main.ts
cat /output/entry.txt
```
